# Contributing

CodeSpace welcomes focused improvements to its browser editor, virtual file system, preview pipeline and accessibility.

## Good first contributions

- Keyboard and screen-reader accessibility
- Mobile editor and preview fixes
- Clearer error messages
- Documentation and example projects
- Reproducible file import/export bugs
- Performance improvements for larger workspaces

Fork the repository, create a descriptive branch, test in at least one Chromium browser and one additional modern browser, then open a pull request linked to an issue. Avoid new dependencies unless the issue specifically requires one.
